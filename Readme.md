# Explore Lucknow 🕌✨

Discover the rich culture, heritage, and modern attractions of Lucknow through this interactive web project.

## 🚀 Features
- Showcases historical monuments, food, and traditions
- Responsive design for mobile and desktop
- Built with **HTML, CSS, and JavaScript**
- Easy to navigate and visually engaging

## 📂 Project Structure
- `index.html` → Main landing page
- `style.css` → Styling and layout
- `script.js` → Interactive elements

## 🎯 Purpose
This project is designed to highlight the beauty of Lucknow while practicing frontend development skills.
